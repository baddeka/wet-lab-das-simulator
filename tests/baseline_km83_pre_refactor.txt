######## hill.py ########
=== how much of a 1.667x input difference reaches the output ===
  f(x) = x^n / (K^n + x^n),  K = 0.10 uM

  x/K      n=1: f       n=2: f                 
  0.1      0.091        0.010       
  0.3      0.231        0.083       
  1.0      0.500        0.500       
  3.0      0.750        0.900       

  local log-log slope  dlnf/dlnx = n*(1-f):
    far below K  n=1 -> 0.91   n=2 -> 1.98
    at K         n=1 -> 0.50   n=2 -> 1.00
    above K      n=1 -> 0.25   n=2 -> 0.20

  so a 1.667x change in H2O2 becomes, in reporter output:
    far below K  n=1 -> 1.59x   n=2 -> 2.75x
    at K         n=1 -> 1.29x   n=2 -> 1.67x
